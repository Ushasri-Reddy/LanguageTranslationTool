
# Language Translation Tool

A Python-based desktop application that translates text between multiple languages using a graphical user interface (GUI).

## Features

- Translate text between supported languages.
- Select source and target languages.
- Swap source and target languages.
- Copy translated text to the clipboard.
- Clear input and output text.
- Built-in translations for selected common phrases.
- Online translation using the MyMemory translation service.
- User-friendly interface built with Tkinter.

## Technologies Used

- Python
- Tkinter
- Requests
- MyMemory Translation API

## Supported Languages

- English
- Hindi
- Telugu
- Tamil
- Kannada
- Spanish
- French
- German
- Japanese
- Chinese

## Requirements

- Python 3
- Internet connection for online translations
- Python Requests library

## Installation and Usage

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   py translator.py
   ```

6. Select the source and target languages.
7. Enter the text and click **Translate**.

## Limitations

- Online translations depend on the availability of the MyMemory service.
- Translation results may not always be accurate.
- Built-in translations are available only for selected phrases and language pairs.
- An internet connection is required for other translations.
